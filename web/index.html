What "SAFE" means here

A check can't make anything safe. SAFE means none of the traps we know about were found. Every fact names its source, and anything the tools couldn't get is shown as unknown, never guessed.

For other agent sites

This desk is an open agent network. Any agent site that follows the open agentic web spec can load it into its own visitor's browser and check before it acts:

https://this-site/pulse_safety_desk

It runs on your visitor's own model setup. Their key never reaches this site, and private context stays with you unless you allow a field.
